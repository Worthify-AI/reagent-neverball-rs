# Menu translation catalogs

These JSON dictionaries contain exact nonplural translations decoded from the licensed compiled Neverball GNU gettext catalogs distributed by Ubuntu. They add no machine-generated translation text. English remains the fallback when a catalog lacks a string. The selected languages are German, Spanish, French, Italian, Brazilian Portuguese, Dutch, Polish, and Russian; selection is limited to the character coverage supported by the current bundled font.

Neverball translations are copyright their contributors and distributed under GPL-2.0-or-later. See ../COPYRIGHT.debian and the translator credits in the corresponding preferred-form catalogs retained under assets/neverball/source-full/po/. Those .po files are redistribution inputs, not implementation-code inputs. The original engine source was not used.

language-manifest.json records the original compiled catalog path and SHA-256, generated JSON path and SHA-256, and the matching preferred-form .po SHA-256. SOURCE-ASSETS.json records the authoring archive origin and each retained .po asset. The original runtime-asset inventory remains unchanged; this manifest identifies the derived translation dictionaries separately.
